### `components/ui/Dialog.tsx` (`"use client"`)
```ts
export interface DialogProps {
  open: boolean; onClose: () => void;
  labelledBy?: string;   // id of the visible heading (preferred)
  label?: string;        // aria-label when there is no heading
  describedBy?: string;
  children: ReactNode;
  className?: string;       // outer fixed wrapper (z-[100], flex-centred, p-4)
  panelClassName?: string;  // panel; merged via tailwind-merge (default: rounded-3xl bg-white p-6 sm:p-8 text-ink)
  initialFocusRef?: RefObject<HTMLElement | null>;
  size?: "md" | "lg" | "xl" | "full";  // max-w-lg | max-w-2xl (default) | max-w-5xl | ~90rem & full height
}
export function Dialog(props: DialogProps): JSX.Element | null;
export function DialogCloseButton(props: ButtonHTMLAttributes<HTMLButtonElement>): JSX.Element; // 44px, aria-label "Close" default
```
Behaviour: portal to `document.body` (nothing rendered during SSR/hydration); scrim `bg-brand-950/70` click closes (only if the press started on the scrim); `role="dialog" aria-modal="true"`; focus → `initialFocusRef` | first focusable | panel; Tab/Shift+Tab trapped; Escape closes (bubble phase — an inner widget that handles Escape should `preventDefault()`); all other body children get `inert`; body scroll locked (scrollbar width compensated); all restored on close and focus returns to the opener; nested dialogs supported (top-most handles keys). Panel `max-h-[calc(100dvh-2rem)] overflow-y-auto overscroll-contain`. Animated with AnimatePresence (opacity + small y/scale; root MotionConfig makes it reduced-motion aware). **No built-in close button.**
```tsx
const [open, setOpen] = useState(false);
<Dialog open={open} onClose={() => setOpen(false)} labelledBy="fees-title" size="xl">
  <div className="flex items-start justify-between gap-4">
    <h2 id="fees-title" className="font-display text-2xl font-bold">Fees</h2>
    <DialogCloseButton onClick={() => setOpen(false)} />
  </div>
  …
</Dialog>
```
**Layering rule:** floating CTAs / sticky bars must use `z-50` or lower (ScrollProgress is z-[70]; Dialog z-[100]; skip link z-200).

### `components/ui/Button.tsx`
- `Button`, `LinkButton` — props unchanged: `variant?: "primary" | "amber" | "outline" | "ghost" | "white"`, `size?: "sm" | "md" | "lg"`, `className?`, plus native button / anchor attrs (`LinkButton` requires `href`).
- Sizes: `sm` = min-h-10 (40px) text-sm; `md` = min-h-12 (48px) text-base; `lg` = min-h-14 (56px) text-base. `min-h` (not fixed `h`) so long labels can wrap on phones.
- Focus: `ring-2 ring-brand-950 ring-offset-2 ring-offset-white` (visible on paper and on forest).
- **Behaviour change:** `Button` now defaults to `type="button"`. Submit buttons must pass `type="submit"` (RequestDemoForm already does).
- New: `buttonClasses({ variant?, size?, className? })` returns the class string (for `<summary>`, `<a>` outside next/link, etc.); types `ButtonVariant`, `ButtonSize`.

Props unchanged plus optional `as?: "h1" | "h2" | "h3"` (default h2) and `id?: string`. Eyebrow 12px, `tracking-[0.08em]`, `text-amber-700` on `bg-amber-500/15` (light) / `text-amber-300` on `bg-white/10` (dark). Title `text-ink`; description `text-ink-muted` (dark sections: `text-white/85`).

### `components/ui/Badge.tsx`, `components/ui/Container.tsx`

### `components/landing/motion-primitives.tsx` (`"use client"`)

- `brand-50…950`: #EEF3EF #DCE6DF #BACDBF #93AF9C #6F917B #5A7F6B #4A6E5D #3A5A4B #2F4A3E **#263E34 (900)** **#1E3329 (950)**. brand-950 is one step deeper than the canvas #263E34 so it reaches 12:1 on paper.

- `cream-50` = paper, `cream-100` = #EFECE1. `background`/`foreground` = paper/ink.

Other globals: `.skip-link`; `#main` scroll-margin; base `:focus-visible` outline (ink outline + white halo, in `@layer base` so utilities override); `.spatial-*`, `.bg-grain`, `.bg-dot-grid`, `::selection` now use tokens; keyframes kept plus new `animate-cue`. **Reduced motion (site-wide):** every animation is cut to one 0.01ms iteration and transitions to 0.01ms (except `.animate-spin`), and `animate-blob/float/float-slow/pulse/ping/bounce/pulse-ring/marquee/cue` get `animation: none`.
