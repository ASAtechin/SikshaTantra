- `app/privacy/page.tsx`, changed to match `app/api/lead/route.ts` and `lib/email.ts` exactly:
  - L105–106: mentions the optional "which ERP or software" field.
  - L108: consent time is recorded (`consentAt`).
  - L111–113: IP is held in server memory, counted over 10 minutes, not emailed or saved, and cleared on restart. ("Briefly" was inaccurate: entries are only pruned once the map exceeds 5,000.)
  - L116–118: when Turnstile is on, the server sends the IP to Cloudflare (`remoteip`); when it is off, nothing goes to Cloudflare.
  - L137–138: the acknowledgement email repeats name, school, boards and areas but not the message.
  - L149–150: the database copy is stored only "if a database is configured", and the provider is "to be confirmed". The previous "MongoDB Atlas" claim cannot be verified from the code; Vercel hosting is kept because `next.config.ts` and `lib/site.ts` reference `siksha-tantra.vercel.app`.

This was a banned phrase, and it contradicted the module's POCSO framing (a report must never be held back). Reworded to match `lib/modules-data.ts`: "Concerns recorded and escalated straight away, with case records limited to your child-protection committee, and never holding back a report to the police or SJPU under POCSO."

  - The old "Experience Blueprint" and "Curriculum Content Boundary" sections (zoom/pan canvas, command dock, `createDemoTextbook`) replaced with a short "Simulator and Library Boundaries".
  - Env table: `LEAD_NOTIFICATION_EMAIL` now required with no default (personal Gmail removed); added `NEXT_PUBLIC_CONTACT_EMAIL`, `NEXT_PUBLIC_WHATSAPP_NUMBER`, `NEXT_PUBLIC_BOOKING_URL`, both Turnstile keys, `NEXT_PUBLIC_SITE_URL` and the verification tokens; Ethereal marked test-only; note that `NEXT_PUBLIC_*` values need a rebuild.
